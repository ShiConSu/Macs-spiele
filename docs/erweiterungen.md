# Erweiterungen: Prüfliste

Hier steht jede Erweiterung (Skill, Plugin, MCP-Server), bevor sie benutzt wird.
Ohne Eintrag mit Stufe APPROVED oder RESTRICTED wird nichts installiert.

## Wie geprüft wird

| Art | Risiko | Prüfung |
| --- | --- | --- |
| Skill nur aus Markdown, ohne Skripte | gering | Text lesen, auf versteckte Anweisungen achten, Commit-Hash notieren |
| Skill oder Plugin mit Skripten oder Hooks | mittel | Skripte Zeile für Zeile durchgehen, Netzwerkzugriffe suchen, Hash festschreiben |
| MCP-Server | hoch | Nur offizielle oder selbst geprüfte, nur nötige Rechte, Zugangsdaten nie ins Repo |

Herkunft unterscheiden: **von Anthropic gebaut** · **von Anthropic gelistet** (kann Drittanbieter sein) · **Community**.
Updates werden neu geprüft.
