# MACS Spiele

Kleine Browser-Spiele und Web-Apps, gebaut beim Lernen mit Claude.

Live: https://shiconsu.github.io/Macs-spiele/

## Aufbau

- `index.html` – Startseite
- `spiele/<name>/index.html` – jedes Spiel bekommt einen eigenen Ordner
- `CLAUDE.md`, `.claude/` – Regeln und Helfer für Claude Code
- `docs/ausbau-roadmap.md` – wie das Setup später wachsen kann
